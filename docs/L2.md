# OOP Lesson 02

## Class and Object

A Class is a blueprint for creating Objects.

Example:

```python
class Joint:
    ...
```

`Joint` is a Class.

Objects can be created from this Class:

```python
shoulder = Joint(...)
elbow = Joint(...)
wrist = Joint(...)
```

Each Object is also called an Instance of the Class.

---

## `__init__`

`__init__` is a special Python method used to initialize a newly created Object.

Example:

```python
def __init__(self, name, min_angle, max_angle):
    self.name = name
    self.min_angle = min_angle
    self.max_angle = max_angle
    self.position = 0
```

`__init__` is not a file.

The file `__init__.py` is a different concept related to Python packages.

---

## `self`

`self` refers to the Object on which the current Method is being executed.

Example:

```python
shoulder.move_to(30)
```

Inside `move_to()`:

```python
self
```

refers to the `shoulder` Object.

Conceptually:

```python
shoulder.move_to(30)
```

is similar to:

```python
Joint.move_to(shoulder, 30)
```

---

## Instance Variable

An Instance Variable belongs to one specific Object.

Example:

```python
self.name
self.position
self.min_angle
self.max_angle
```

Each Joint Object has its own values.

Example:

```text
shoulder.position = 30
elbow.position = 60
wrist.position = -20
```

Changing one Object does not automatically change the others.

---

## Class Variable

A Class Variable belongs to the Class itself and is shared between its Instances.

Example:

```python
class Joint:
    joint_count = 0
```

It can be accessed using:

```python
Joint.joint_count
```

If three Joint Objects are created, `joint_count` can be used to store the total number of created joints.

---

## Method

A Method is a function defined inside a Class.

Example:

```python
def move_to(self, angle):
    self.position = angle
```

It is normally called through an Object:

```python
shoulder.move_to(30)
```

---

## Object and Memory

When an Object is created:

```python
shoulder = Joint(...)
```

Python creates a Joint Object in memory.

The variable `shoulder` refers to that Object.

Conceptually:

```text
shoulder
   |
   v
Joint Object
```

Two different Objects normally have different identities:

```python
id(shoulder)
id(elbow)
```

Two variables can also refer to the same Object:

```python
another_name = shoulder
```

In this case:

```text
shoulder --------\
                  > Joint Object
another_name ----/
```

---

## Robot Composition

A RobotArm can contain several Joint Objects:

```text
RobotArm
|
|-- shoulder -> Joint
|-- elbow    -> Joint
|-- wrist    -> Joint
```

This relationship is called Composition.

The RobotArm HAS-A Joint.

---

## Important Mental Model

An Object contains:

```text
Object
=
State
+
Behavior
```

For a Joint:

```text
State:
name
position
min_angle
max_angle

Behavior:
move_to()
show_status()
```

The key distinction is:

```text
self.position
```

means the position belonging to one specific Joint Object.

While:

```text
Joint.joint_count
```

means a value belonging to the entire Joint Class.
