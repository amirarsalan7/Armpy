The first goal is only to establish communication with the CM-550 controller.

Motor movement is not enabled at this stage.

CM-550 Basic Communication Data
Default ID:       200
Model Number:     450
Protocol:         2.0
PC baud rate:     57600

The CM-550 can be connected directly to a PC through its Micro-USB port.

DynamixelConnection

The hardware communication layer is represented by a Python class:

DynamixelConnection
│
├── device_name
├── baudrate
├── protocol_version
├── PortHandler
└── PacketHandler

device_name, baudrate, and protocol_version are Instance Variables.

Composition

DynamixelConnection contains other Objects:

DynamixelConnection Object
│
├── PortHandler Object
└── PacketHandler Object

This is an example of Composition.

PortHandler

PortHandler manages the operating-system communication port.

Example:

PortHandler("/dev/ttyACM0")

Conceptually:

PortHandler
=
Where should data be transmitted?
PacketHandler

PacketHandler creates and processes DYNAMIXEL protocol packets.

Example:

PacketHandler(2.0)

Conceptually:

PacketHandler
=
How should the data packet be formatted?
Opening a Port

Opening /dev/ttyACM0 only proves that Python can access the serial port.

It does not yet prove that the CM-550 is responding.

Ping

A Ping sends a DYNAMIXEL instruction packet to a specific device ID.

Example:

connection.ping(200)

A successful CM-550 response should report its model number:

450

A successful Ping verifies packet-level communication:

Python
→ CM-550
→ Python
self

For:

connection.ping(200)

inside:

def ping(self, device_id):

the values are conceptually:

self      = connection
device_id = 200

Therefore:

self.port_handler

means the PortHandler belonging to that particular DynamixelConnection Object.
